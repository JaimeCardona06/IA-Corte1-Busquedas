## Descripción del Proyecto
Desarrollo de las actividades prácticas del primer corte sobre algoritmos de búsqueda:
búsqueda no informada (BFS/DFS), búsqueda informada, y búsqueda adversarial (Minimax y Poda Alfa-Beta).

## Estructura del Repositorio
* `notebooks/01_busqueda_no_informada_bfs_dfs.ipynb`: Implementación y experimentos con BFS y DFS.
* `notebooks/02_busqueda_informada.ipynb`: Implementación y análisis de algoritmos informados (A*, Greedy, etc.).
* `notebooks/03_busqueda_adversarial_minimax.ipynb`: Modelado de juego y algoritmo Minimax.
* `notebooks/04_busqueda_adversarial_poda_alfabeta.ipynb`: Optimización del juego con Poda Alfa–Beta y comparación.

## Instrucciones de Ejecución
1. Clonar el repositorio: 

- git clone https://github.com/TU_USUARIO/IA-Corte1-Busquedas.git

- cd IA-Corte1-Busquedas

2. Instalar las dependencias:

- pip install -r requirements.txt

3. Abrir Jupyter Notebook o VS Code y ejecutar las celdas en orden secuencial en cada archivo `.ipynb`.
